# GitHub Pages

This is a buildless static site. Publish `main` from `/ (root)` in repository Settings → Pages → Build and deployment → Deploy from a branch. No Node installation or build command is needed. `.nojekyll` prevents Jekyll processing. Relative asset paths work under the repository subpath.

Expected URL after Pages is enabled: https://oddtotheendart-source.github.io/hashani-navy/

This instruction prepares Pages; it does not assert that Pages is enabled or a deployment has succeeded.

## Editing

`index.html` contains the banner and records layout, `styles.css` the responsive presentation, and `site.js` the task/scroll catalogue. Source provenance and content gaps are documented in `CONTENT.md`. Add exact scroll text separately from editorial explanations, with its recorded attribution. Supply an approved Elius portrait before replacing the initial-letter banner placeholder.
